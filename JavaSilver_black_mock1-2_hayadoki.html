黒本模試①・② 早解き表

← はじめの画面に戻る
使い方：問題を見たら、まず「最初に見る」を1つ確認。該当したら「速解き」のルールで即判定し、必要なときだけコードを追います。問題一覧ではなく、模試①・②で繰り返し使える判定ルールに絞っています。
01

コンパイル可否を最初に潰す

最初に見る：実行結果を追う前に、宣言・型・アクセス・未実装・到達不能を確認。1か所でも違反ならそこで終了。

速解き：varがフィールド/戻り値、具象クラスの抽象メソッド未実装、親に引数なしコンストラクタがない、catchが親→子、continue後の文。

該当例：模試①: 6,12,32,33,52,53,55 / 模試②: 1,3,14,24,37,43,50

02

参照型は左、実行メソッドは右

最初に見る：「呼べる候補」は左辺の型。「オーバーライド後に実行されるメソッド」は右辺の実体型。

速解き：A a = new B(); なら a.bye() はAに無ければ不可。a.hello()はBがoverrideしていればB版。

該当例：模試①: 10,13,38,42 / 模試②: 7,17,35,36

03

フィールドは左辺の型

最初に見る：フィールドは動的ディスパッチしない。参照型を見て即決する。

速解き：A a = new B(); a.num → A.num。メソッドとの違いを混ぜない。

該当例：模試①: 28,42,51 / 模試②: 7,27,36

04

Stringは「戻り値を代入したか」

最初に見る：Stringは不変。concat / replace / substring を見たら、結果を代入しているかだけ先に見る。

速解き：str.substring(...); だけならstrは変化なし。null.concat(...)ならNPE。

該当例：模試①: 35,56,60 / 模試②: 11,44,48

05

配列は length-1 と null 初期値

最初に見る：添字の上限は length-1。参照型配列の生成直後の要素はnull。多次元は1段ずつ型を落とす。

速解き：new String[2] → {null,null}。array[length] は範囲外。

該当例：模試①: 14,21,40,57,59,60 / 模試②: 23,40,47,52,53

06

switchは「文か式か」を先に判定

最初に見る：-> はフォールスルーなし。: はbreakの有無を追う。switch式でブロックから値を返すならyield。

速解き：case A -> 処理; は次caseへ落ちない。case A: のbreakなしは下へ落ちる。

該当例：模試①: 16,25,36 / 模試②: 9,21,22,28

07

例外は「発生型→最初のcatch→finally」

最初に見る：catchは子→親。try-with-resourcesはリソースを逆順closeしてからcatch、最後にfinally。

速解き：Exceptionの後にRuntimeExceptionのcatchは到達不能。resource A,BならcloseはB→A。

該当例：模試①: 3,8,26,54,55 / 模試②: 5,8,12,49

08

コンストラクタは this → super → 親から戻る

最初に見る：this(...)を最優先でたどり、次に暗黙/明示super。実際の出力は最深部の親から戻りながら書く。

速解き：new B() → B()→this(4)→B(4)→super()→A()→this(2)→A(2) の順に潜る。

該当例：模試①: 12,46,52,58 / 模試②: 27,38,54

09

interface / abstract は未実装を数える

最初に見る：最後の具象クラスに未実装の抽象メソッドが残っていないかだけ確認。default競合はクラス側で解消。

速解き：A,B双方のdefault hello()を継承したらoverride必須。呼ぶなら B.super.hello()。

該当例：模試①: 33,43,50,53 / 模試②: 13,15,20,55

10

sealedは permits と3修飾子

最初に見る：直接サブタイプがpermits対象か確認し、子は final / sealed / non-sealed のいずれか。

速解き：permits B,C なのにD extends Aは不可。

該当例：模試①: 7,19 / 模試②: 6,16,17

11

recordは「private final + name()」

最初に見る：recordの成分は変更不可。標準アクセサはgetName()でなくname()。標準コンストラクタは全成分を受け取る。

速解き：record Book(String name) → new Book("A") / book.name()。

該当例：模試①: 20 / 模試②: 10

12

オーバーロードとオーバーライドを分離

最初に見る：引数が違えばオーバーロード。overrideは同じ引数で、戻り値は同型または共変。アクセスは狭めない。

速解き：test(Integer) と test(int) は別シグネチャ。protectedをpackage-privateにoverrideは不可。

該当例：模試①: 9,18,42,50 / 模試②: 35,42,51,59

13

ローカル変数・this・staticを区別

最初に見る：ローカル変数には初期値なし。同名引数があれば this.field で区別。staticからインスタンスメンバーを直接触れない。

速解き：int num=num; は未初期化ローカルを読む。value=value は引数への自己代入。

該当例：模試①: 11,28,32 / 模試②: 1,3,26,30,43,56,57,60

14

ループは添字より「更新位置」を見る

最初に見る：前置/後置、continue、breakで更新される箇所をマーク。continueの後は実行されない。

速解き：Bをcontinue、C表示後breakなら出力はA,C。

該当例：模試①: 14,21 / 模試②: 18,21,22,45,46,50

15

コマンドは .java / クラス名 / -d / -cp

最初に見る：javacはコンパイル。javaはクラス名、またはJava 11+の単一ソース実行で.java。-dは出力先、-cpは検索起点。

速解き：javac -d build ... → java -cp build ex15.Main。

該当例：模試①: 30,37,49 / 模試②: 2,31
