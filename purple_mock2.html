問題文・コード・選択肢

次のプログラムがあります。

public interface Playable {
    // insert code here
    void play();
}
class MusicPlayer implements Playable {
    public void play() {
        System.out.print("playing..." + SPEED + "x");
    }
}
A. protected double SPEED = 1.25;
B. private double SPEED = 1.25;
C. final double SPEED = 1.25;
D. public abstract SPEED;
E. public double SPEED;
F. static double speed = 1.25;
回答を選択
正答・解説を表示
正答：C

正解の理由

A × protected はインターフェースのフィールドには指定できません。

B × private もこのフィールド宣言には指定できません。

C ○ final double SPEED = 1.25; は有効。暗黙的に public static final。

D × 型がないうえ、フィールドに abstract は指定できません。

E × public double SPEED; は初期化されていません。インターフェースのフィールドは final になるため、宣言時に値が必要です。

F △/× static double speed = 1.25; という宣言自体はインターフェースで有効ですが、名前が小文字の speed です。コードが参照しているのは大文字の SPEED なので、この問題の空欄としては不正解です。

覚え方

「インターフェースの変数は全部 public static final」

要点

インターフェースのフィールドは暗黙的に public static final

final フィールドなので初期値が必要

今回は大文字の SPEED を宣言するCが正解
