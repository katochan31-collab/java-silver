問9

問題文・コード・選択肢

次のプログラムがあります。

sealed class Base {}
// insert code here
final class concrete extends Base {}

// insert code hereに記述できるクラス宣言として正しいものはどれですか。(4つ選択)

A. public class Derived {}
B. private class Derived {}
C. final class Derived {}
D. static class Derived extends Base{}
E. abstract class Derived{}
F. abstract final class Derived {}
G. sealed final class Derived {}
H. non-sealed class Derived extends Base {}
回答を選択
正答・解説を表示
正答：A, C, E, H

正解までの考え方

// insert code hereに入る宣言は、すべてトップレベルクラスとして扱います。まずトップレベルで使える修飾子かを確認し、次にBaseを直接継承する場合だけsealedクラス特有の条件を確認します。

先に覚えるルール

  • トップレベルクラスのアクセス修飾子はpublicまたは省略だけです。private、protected、staticは指定できません。
  • abstractとfinalは同時に指定できません。abstractは継承を前提とし、finalは継承を禁止するためです。
  • sealedとfinalも同時に指定できません。sealedは許可したサブクラスへの継承を認めますが、finalはすべての継承を禁止するためです。
  • sealedクラスを直接継承するクラスには、final、sealed、non-sealedのいずれかが必要です。
  • Baseを継承していない独立したクラスには、Baseのsealed制約は適用されません。

各選択肢の解説

  • A：○ public class Derived {} は独立したトップレベルクラスです。publicはトップレベルクラスに指定でき、Baseを継承していないためsealedの制約も受けません。
  • B：× private class Derived {} のprivateはトップレベルクラスに指定できません。privateを使えるのは、ほかのクラスの内部に宣言するネストしたクラスなどです。
  • C：○ final class Derived {} は有効です。finalは「このクラスを継承させない」という意味で、通常のトップレベルクラスに指定できます。
  • D：× static class Derived extends Base {} のstaticはトップレベルクラスに指定できません。staticを指定できるのは、ほかのクラスの内部に置くstaticネストクラスです。
  • E：○ abstract class Derived {} は有効です。abstractクラスは直接newできませんが、トップレベルクラスとして宣言できます。Baseを継承していないため、sealed直下の条件も関係ありません。
  • F：× abstract final class Derived {} は無効です。abstractはサブクラスで完成させることを前提としますが、finalはサブクラス化を禁止するため、意味が矛盾します。
  • G：× sealed final class Derived {} は無効です。sealedは許可したサブクラスへの継承を認め、finalは継承を全面的に禁止するため、同時には指定できません。
  • H：○ non-sealed class Derived extends Base {} は有効です。sealed class Baseの直接のサブクラスなので、final、sealed、non-sealedのいずれかが必要です。non-sealedを付けると、Derived以降の継承制限を解除できます。

短いコード例

sealed class Base permits Closed, Open, Limited {}

final class Closed extends Base {}       // ここで継承終了
non-sealed class Open extends Base {}    // この先は自由に継承可能
sealed class Limited extends Base        // 次の継承先をさらに限定
        permits Child {}
final class Child extends Limited {}

試験での見分け方

最初にextends Baseの有無を見ます。なければ通常のトップレベルクラスの修飾子を判定し、あれば「sealed直下はfinal・sealed・non-sealedのどれか」と確認します。
